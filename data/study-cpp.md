# My Programming Fundamentals notes (C++)

## Why it matters to me
Programming Fundamentals was my first programming course, where I learned C++. It taught me to think step by step and to control the flow of a program.

## Conditionals
The if statement runs code only when a condition is true. With if-else I choose between two paths, and with else-if I choose between many. Conditions use comparison operators such as ==, !=, <, > and logical operators such as && (and), || (or) and ! (not). A common beginner mistake is writing = instead of == in a condition.

## Switch statements
A switch statement picks one of many cases based on the value of a variable, such as a menu choice. Each case usually ends with break, otherwise execution falls through into the next case. The default case handles values that do not match any case. Switch is neater than a long chain of else-if when comparing one variable to fixed values.

## Loops
A for loop is best when I know how many times to repeat. A while loop repeats as long as a condition is true, checking before each round. A do-while loop runs the body at least once and checks afterwards, which is useful for menus and input validation. The break statement exits a loop early and continue skips to the next round.

## Practice
My exercises combined these ideas, for example menu-driven programs with switch, number patterns with nested loops, and programs that make decisions with if-else. Doing them taught me to trace code by hand and to test with different inputs.
